## RD2D 丝印的新线索（候选，未确认）

用户在上述扫描无响应后报告“上面写了个 RD2D”。目前按 DO2 附近黑色小器件的顶面丝印理解，但未得到能确认该颗器件、脚数和完整标记的新近照。

若其封装为 SC-70-6 / SOT-363 六脚，优先候选是 **Si1551DL**。依据 [Vishay Siliconix 原厂署名数据手册，分销商镜像](https://www.allelcoelec.my/datasheets.f2/SI1551DL-T1-GE3.pdf)（doc 71255，Rev.D，2010-04-19）首页：该型号的 Part Code 为 RD，旁边另有批次和日期码；不能把用户所报 2D 确定解码，也不能由 RD2D 唯一认定型号。

该型号内部是 N 沟道和 P 沟道两个 MOS。其芯片 2 脚 G1、5 脚 G2 是栅极控制端；这里是小器件自身的脚号，**不是 Air724UG 的 GPIO2、GPIO5**。确认封装及方向后，可以从这两个控制端沿电阻或中间器件追到模组；不保证存在直接通断关系。双 MOS 本身不能证明 DO2 由两个 GPIO 控制，也不能确认高边/低边拓扑。手册仅保证 |VGS| 为 2.5/2.7/4.5 V 时的导通电阻，不能用阈值电压推定 1.8 V 已充分导通。

以上保留为未确认的辨识线索。用户随后选择跳过器件近照辨认、继续换 GPIO 测试，当前不再要求提供近照；不据该候选推定 DO2 映射。

| 对象 | 控制方式候选 | 推断依据与限制 |
| --- | --- | --- |
| 出纸电机 | 一路 GPIO，经可能的电平转换/开关管控制单向启停 | 独立器件区域支持单向开关这一候选；“+”只表示端子极性，不能证明该端固定供电。尚未确定高边开关、低边开关或桥式驱动，也不能确定高/低有效或是否使用 PWM |

## 数据手册确认的事实

### GPIO23 与 SIM 在位检测

根据 [Air724UG 硬件手册 V3.7](https://docs.openluat.com/air724ug/product/file/Air724UG_%E7%A1%AC%E4%BB%B6%E8%AE%BE%E8%AE%A1%E6%89%8B%E5%86%8C_V3.7.pdf)引脚表，USIM_CD 与 GPIO23 共用物理8脚。GPIO输出和该脚的硬件卡在位检测不能同时使用；SIM本身的CLK/DATA/RST/VDD为其他脚，因此不用USIM_CD并不等于不能读卡联网。实际使用还须确认底层没有启用此硬件检测，以及板上卡座检测触点没有与GPIO输出产生电气冲突。

当前src及官方V2.4.4默认库没有主动启用CSDT/热插拔检测的代码；CPIN/ICCID/CIMI查询和SIM_IND消息不是该检测已启用的证据。本轮未读取CORE当前/持久配置，不能写成“检测已确认关闭”。此前三脚诊断未增加AT/SIM设置是实现事实，不能推成任意接线与配置均兼容。现有DO2电压现象也尚不足以判定存在SIM复用冲突。

[RZ7886 原厂署名数据手册（立创镜像）](https://atta.szlcsc.com/upload/public/pdf/source/20180613/C128852_BAAE7924E869DB4853C0D962680B5688.pdf) 署名无锡睿智微电子有限公司，2011.7。该链接是文档镜像，不是当前厂商官网。

RZ7886 为双向直流电机驱动器：1 脚 BI、2 脚 FI 是逻辑输入；3 脚 GND、4 脚 Vcc；5/6 脚 FO、7/8 脚 BO 是功率输出。下表描述芯片输入端，不能直接当作未知板级 GPIO 电平表。

| FI（2 脚） | BI（1 脚） | 芯片输出 |
| --- | --- | --- |
| 高 | 低 | 一个方向 |
| 低 | 高 | 相反方向 |
| 低 | 低 | 两端高阻，停止驱动 |
| 高 | 高 | 两端低电平，制动 |

[合宙 Air724UG GPIO 官方教程](https://docs.openluat.com/air724ug/luatos/app/driver/gpio/) 使用旧版 `pins.setup(pio.P0_x, initial_level)` 控制 GPIO 高低电平，并说明 GPIO 分属不同电压域。`pio.P0_18` 表示 GPIO18，与这块定制板的 TP18 丝印不存在已知对应关系。合宙模组手册不能替代该定制 PCB 的原理图。

## 对现有程序的影响

历史电机模板实现了 3 秒通、3 秒断，但映射仍未确认、配置保持禁用。新版 0.3.0 的 `START` 已改为单次换水入口，不再运行该电机模板；新版映射也保持未配置。最近板上确认的是 0.2.8 并已 STOP。GPIO5 HIGH 时的 6.1V 与 GPIO23 在 STOP 后的近 0V 尚不足以确定各自完整启停方法，后续仍需核对实际驱动连线和关断表现。

“USB 插座—出纸电机—RZ7886”区域的器件字样、走线和断电连通性仍是需要补充的证据；受限诊断获得的电压变化也须与具体测量端子对应，不能仅凭程序日志认定电机接线。

## 对“轮询引脚定位”的判断

- 周期读取 0/1 不能识别外接器件身份，不能自动找出电机控制脚。
- 当前 LuaTask V2.4.4 的 `pins.setup(pin)` 会调用 `pio.pin.close` 并设置为输入；已配置输出后，返回函数无参数调用也会切回输入。因此不能把这种遍历当作完全保持硬件状态的读取。
- 原生 `pio.pin.getval` 在 Lua 层没有附加配置操作，但尚未确认其对未初始化、外设复用或未供电电压域的引脚能否可靠反映实际电平；也未找到可完整保存和恢复 pinmux/方向/电压域的公开接口。
- 逐脚拉高/拉低属于主动电气测试。全 GPIO 扫描可能改变启动/通信/板上外设状态或与已有输出冲突，不能只靠缩短脉冲消除这些问题。
- 受限候选测试是可用的调试方法，但前提是确认候选的用途、电压域、是否存在外部驱动及停止方式；试验时先断开电机和其它负载，用直流电压档观察输出响应。仅拔掉电机不等于其余电路已可随意扫描。
- 第一组 GPIO24–28 与第二组 GPIO15/14/19/18 均已执行受限诊断，用户均未观察到电压变化，不能排除使能组合。第三组 GPIO5 的高电平阶段获得出纸端约 6.1 V 的用户反馈，暂列强候选；完整映射仍未确认。

接口依据：`tools/vendor/luatools/resource/8910_script/script_LuaTask_V2.4.4/lib/pins.lua` 及[合宙官方 GPIO 教程](https://docs.openluat.com/air724ug/luatos/app/driver/gpio/)。
